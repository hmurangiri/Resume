One-column premium responsive HTML/CSS resume website designed for GitHub Pages.

## What changed

- Converted the layout to one column.
- Added a sticky navigation menu.
- Added a mobile hamburger menu with CSS only.
- Added smooth scrolling to resume sections.
- Improved desktop and mobile responsiveness.

## Files

- `index.html`
- `style.css`
- `README.md`

## How to publish on GitHub Pages

1. Create a GitHub repository, for example `resume`.
2. Upload `index.html`, `style.css`, and your PDF CV.
3. Upload the files to GitHub. This version does not include a Download CV button.
4. Go to **Settings** → **Pages**.
5. Choose:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/root`
6. Save and wait for GitHub to publish the site.

Your link will look like:

`https://yourusername.github.io/resume/`
